# JobForge Deployment Guide

## Architecture
- **Frontend**: React/Vite → **Vercel**
- **Backend**: FastAPI → **Railway**
- **Database**: PostgreSQL → **Railway** (included)

---

## Prerequisites

1. **GitHub account** (free)
2. **Railway account** (free, need credit card but free tier is generous)
3. **Vercel account** (free)
4. **API Keys**:
   - Groq API key: https://console.groq.com
   - Gemini API key: https://makersuite.google.com/app/apikey

## Step 1: Initialize Git & Push to GitHub

```bash
cd d:\JobForge

# Initialize git
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit: JobForge deployment"

# Create repo on GitHub (via web)
# Then push:
git remote add origin https://github.com/YOUR_USERNAME/jobforge.git
git branch -M main
git push -u origin main
```

## Step 2: Deploy Backend to Railway

### Option A: Railway CLI (Recommended)

```bash
# Install Railway CLI
npm install -g @railway/cli

# Login to Railway
railway login

# Initialize Railway project
cd d:\JobForge
railway init

# Link to GitHub repo (follow prompts)

# Add PostgreSQL plugin
railway add --plugin postgres

# Set environment variables
railway variables set GROQ_API_KEY=your_key_here
railway variables set CORS_ORIGINS=http://localhost:5173,https://your-frontend.vercel.app
# DATABASE_URL is auto-generated by Railway

# Deploy
railway up
```

### Option B: Railway Web Dashboard

1. Go to https://railway.app
2. Click "New Project"
3. Select "Deploy from GitHub repo"
4. Connect your GitHub account and select `jobforge` repo
5. Railway auto-detects Python
6. Add PostgreSQL plugin:
   - Click "Add service" → "PostgreSQL"
7. Set environment variables in project settings:
   - `GROQ_API_KEY`: your Groq key
   - `CORS_ORIGINS`: (see below)
   - DATABASE_URL is auto-generated
8. Deploy happens automatically

**Get your Railway Backend URL**: 
- Go to Deployments → View Logs → Look for the public URL

---

## Step 3: Deploy Frontend to Vercel

1. Go to https://vercel.com
2. Click "New Project"
3. Import your GitHub `jobforge` repo
4. **Framework Preset**: Vite
5. **Root Directory**: `./frontend`
6. **Build Command**: `npm run build`
7. **Output Directory**: `dist`
8. Environment Variables:
   ```
   VITE_API_URL=https://your-railway-backend.railway.app
   ```
9. Click "Deploy"

**Update CORS** once you have Vercel URL:
- Go back to Railway dashboard
- Update `CORS_ORIGINS` env var to include your Vercel URL
- Redeploy: Railway will auto-redeploy

## Environment Variables Checklist

### Railway (Backend)
- [ ] `GROQ_API_KEY` - Groq API key
- [ ] `CORS_ORIGINS` - Include both local & Vercel URLs
- [ ] `DATABASE_URL` - Auto-generated by PostgreSQL plugin
- [ ] `GEMINI_API_KEY` - (if used by services)

### Vercel (Frontend)
- [ ] `VITE_API_URL` - Railway backend URL

## Troubleshooting

### Backend deploys but frontend can't reach it
- Check `CORS_ORIGINS` in Railway includes your Vercel domain
- Check `VITE_API_URL` in Vercel is correct (no trailing slash)
- Verify both are deployed and running

### Database connection fails
- Ensure PostgreSQL plugin is added in Railway
- Check `DATABASE_URL` env var exists and is correct
- Run migration if needed: `python -m alembic upgrade head`

### Static files 404 on Vercel
- Ensure `vite.config.js` has correct build output
- Check `.vercelignore` doesn't exclude important files
